# 📊 Análise Exploratória de Vendas — Superstore Sales

## 📌 Descrição do Projeto
Este projeto consiste em uma **Análise Exploratória de Dados (EDA)** aplicada a um conjunto de dados de vendas do varejo (Superstore Sales).  
O objetivo é explorar, limpar e analisar os dados para identificar **padrões, tendências e insights relevantes para o negócio**, utilizando Python e bibliotecas amplamente adotadas na área de Ciência de Dados.

O projeto foi desenvolvido em **Google Colab**, com carregamento direto dos dados a partir do Kaggle.

---

## 🎯 Objetivos
- Compreender a estrutura e a qualidade dos dados
- Realizar limpeza e preparação básica
- Analisar vendas por **categoria**, **região** e **tempo**
- Criar visualizações claras e interpretáveis
- Demonstrar raciocínio analítico aplicado a dados reais

---

## 🧰 Tecnologias Utilizadas
- **Python 3**
- **pandas** — manipulação e análise de dados
- **matplotlib** — visualização de dados
- **seaborn** — visualizações estatísticas
- **kagglehub** — carregamento de datasets do Kaggle
- **Google Colab** — ambiente de desenvolvimento

---

## 📂 Conjunto de Dados
- **Fonte:** Kaggle  
- **Dataset:** Superstore Sales  
- **Link:** https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting  

O dataset contém informações sobre pedidos, clientes, produtos, categorias, regiões e valores de vendas.
